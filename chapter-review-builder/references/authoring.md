# 写 md 正文（Step 1 读这一份）

> **什么时候读**：摸完素材、动手写 md 之前。

产出的东西叫**「复习资料」**，不叫提纲：提纲只有骨架，复习资料必须每个知识点配一道题、每章末尾有题库和一页速查。

**来源不决定流程**——主干素材定骨架与编号体系，其他素材按 `intake.md` 进入补充层。

## 〇、深度偏好（最先看，决定整份资料的风格）

**几何直观优先**——数学按 Strang 的行图 / 列图口径，物理按物理图像与矢量图。

但每个核心概念后**必须补一段「国内考法」**：坐标计算步骤、矩阵手算流程、判定套路。

目标是「脑子里有箭头，手底下能算数」。只讲直觉不做题，和只讲步骤不给图，都不合格。

## 一、文件头三行（固定）

`@sub` 是标题下的副标题，`@header` 是页眉左格，两行都不能省。

```
# 第X章 章节名（上 / 下 / 拓展）

@sub 科目 · 来源描述 · 定位
@header 科目 · 第 X 章（上）  章节名
```

`@sub` 按**本次实际来源**写：教材 PDF 用「教材名 第N版 · 原书 pA–B」；课件 / 拓展专题 / 笔记没有原书页码，就写「课件第 X 章 \* 标注 + 绪论 pN」这类来源描述，**不要编页码**。

`@header` 分册时带「（上）/（下）/（拓展）」。

## 二、容器速查

写错不会报错，只会静默变成普通段落，动笔前对一遍。完整方言见 `md-dialect.md`。

| 写法 | 用途 |
|---|---|
| `:::goal 核心考点` | 章首目标，每章一个 |
| `:::box 标题` | 正文主体块（国内考法、手算模板、小结） |
| `:::note 降维注释` | 直觉解释、类比 |
| `:::warn 标题` | 易错点、陷阱 |
| `:::code` | 结构块：本章脉络、目录结构、纯文本流程（**无标题**） |
| `:::flow 标题` | 可跨页长列表（题库专用） |
| `:::quiz 【来源】编号 · 标题` | 题卡 |

三条最容易忘的：

1. 每个容器必须以**单独一行** `:::` 结束；
2. 题卡三行固定 `**题**` / `**提示**` / `**答案**`，来源标注写在标题里；
3. 矩阵一律 `bmatrix`，不要用 ASCII 字符画。

## 三、骨架

写成 Markdown 中间稿，便于迭代。

- **核心考点**（`:::goal`，1–2 句说清这章解决什么问题）
- **本章脉络**（`:::code`，用缩进分层：写 `├─` `└─` 即可，引擎渲染时剥掉树符换成缩进、一级节点加粗；行内用 `$…$` 写真公式，分式与 `\limits` 不进树）
- **详细拆解**（按节：定义 → 公式 → 定理/判据 → 几何直观 → 国内考法）
  - 几何直观用 `:::note`，考法用 `:::box`（步骤编号 + 易错点）
- **易错点与极客备忘录**（编号清单 + 代码验证思路，如 `np.linalg.matrix_rank`）
- **附录：题库**（同一知识点超出 1 题的其余题目）
- **一页速查**（公式卡 + 三条必背直觉，**必须是最后一页**）

**骨架与科目无关**，只是叫法不同：数学「定义 → 公式 → 定理 → 几何直观 → 考法」，物理「定律 → 公式 → 适用条件 → 物理图像 → 解题套路」，电路「元件特性 → 方程 → 求解 → 等效变换」。

逐项对应着填，缺哪项补哪项，**不要为了凑骨架编内容**。

另外两条容易漏的：

- **章首概要**：原书每章开头的 overview 不要漏，也**不要单独开一节**——吸收进 `:::goal` 的第二段当引子。
- **跨章去重**：本章概念若前面讲过（如 4.1 的「四个子空间」与 3.5 是同一组对象的维数面），**只做一句回指**（「维数已在 3.5 给出，这里只看正交」）。重讲会让资料变厚，完全不提又会让读者以为是新概念。

## 四、配题规则（强制）

定位是**带例题的复习资料**，不是知识点罗列：**每个知识点至少一道题**，正文「学完即练」。

1. **来源优先级**：教材例题 → 课后习题 → 章末总复习题。都没覆盖的知识点，依据知识库**现场自拟**，难度对标**所用教材本章课后习题的实际水平**——原书就在工作区 `Ebooks\`，翻同节习题确认基线，不另立「国内期末」「竞赛」这类外部标准。
2. **来源标注（强制）**：`【教材例题 5.3】`、`【课后习题 5.2 第 4 题】`、`【总复习题 5】`、`【思考题 X.Y】`、`【课堂例题 第X章 pNN】`（课件原题）、`【自拟】`。自拟题必须显式标注，**严禁冒充教材题或课堂原题**。
3. **自拟题红线**：出完必须自己完整做一遍，给出答案与关键步骤；数值要能算出干净结果；符号记法与本章一致；不出无解题或脱节题。
4. **摆放**：每个知识点正文后紧跟 1 道代表题；同一知识点的多余题目集中放「附录：题库」（速查之前）。
5. 原文的「方框要点」「范例解析 A/B/C」必须全部吸收；习题题型转化为「国内考法」。
6. **课堂素材的标注**：课件原题用 `【课堂例题 第X章 pNN】`，与 `【教材例题】`/`【习题】`/`【思考题】`/`【自拟】` 并列；`pNN` 是幻灯片序号，不是教材页码。
7. **自行推导必须明说**：课件 / 教材只给现象或结论、公式由本资料补出时，在题面或答案注明「自行推导」，并在自检报告「准确度」里列清单；**严禁冒充课堂或教材内容**。
8. **来源编号冲突**：课件节号与教材节号不同时（如课件 3.7 是两体问题、教材 3.7 是角动量守恒），按教材体系顺延并加「课堂扩展」标记，对照表写进 `复习资料\_台账.md`；不要把课件编号直接插进正文。
9. **课堂扩展在出题范围内**：课件 `*` 标注、绪论点名、老师反复强调的扩展内容，只要落在本章范围内，**一律算考点、逐项配题**，不得以「选讲」「拓展阅读」为由略过。跨章的扩展条目登记到 `复习资料\_台账.md` 的待做清单，不要求本章闭合。

## 五、两条防止编造的规则

### 可判定性原则

任何要写进正文的约定或事实，必须能落到一个**可执行校验**上——符号表条目、lint 规则、可复算的数值、或教材页码。

落不到就别写进规范，改写成「举例说明」或删掉。规范本身只放「怎么检查」，不放「记住什么」。

### 来源编号只抄可核实的

只在页面图 / 渲染图上确实看到 `(5.1)`、`例 5.3` 这类编号时才沿用，且与本册标注一一对应；没看清就一律不编号，**绝不按顺序臆造**（如顺手写出 `(5.3)`）。

## 六、跨册回指

拆册后不得保留本册内找不到本体的 `(x.y)` 编号引用。

跨册回指一律用文字，写清册名与节号（如「见第 1 章下册 \*1.8」），不写编号。

## 七、写作口吻与不确定处

- 直接上干货，不写「好的，我来帮你整理」「希望对你有帮助」这类废话。
- 图片模糊、无法确认时，必须用 `[疑似: xxx]` 标出，并在自检报告里单独提示，**严禁瞎编**。
- 图片型公式（扫描 PDF、课件内嵌公式图片、板书照片）一律以**渲染图视觉重建**为准；OCR / `a:t` 文字层的公式视为无效数据，只能用来定位线索。

## 八、符号约定外置

记号约定**不写进正文**，全部维护在 `复习资料\_源稿\<科目>_notation.md`。

构建时引擎从该文件自动把「记号约定」框注入每册首页；正文不手写、不重复解释。不传符号表则不注入，其他科目用不到。

交付前：通用审计全科都跑；`<科目>_lint.py` 存在时另跑，**ERROR 必须为 0**（WARN 需在自检报告里说明）。

**原因**：约定类知识写进规范只会稀释注意力，而且没法校验。外置成「一张表 + 一个脚本」后，约定只有一处真相，错误由机器兜住，新章节自动继承。

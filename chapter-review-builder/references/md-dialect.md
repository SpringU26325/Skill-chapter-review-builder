# md 方言完整手册（写 md 时随时查）

> **什么时候读**：写 md 正文时对照；容器、公式、表格与禁用清单都在这一份里。

源稿是 Markdown，由构建引擎转成 docx。**容器名、标记格式写错不会报错，只会静默变成普通段落**，所以这份手册要照着抄。

## 0. 文件骨架

```markdown
# 第X章 章节名

@sub 科目 · 教材名 第N版 · 原书 pA–B
@header 科目 · 第 X 章  章节名

:::goal 核心考点
一两句话说清"这章在解决什么问题"，再列考试落点。
:::

## 本章脉络

:::code
根 $\mathbf{v}=(v_1,\dots,v_n)$
├─ 分支一 ── 一句话点明它归属于哪一节
│   ├─ 条目的关键式子 $\sqrt{2}$
│   └─ 另一条
└─ 分支二
:::
```

- 第一行必须是 `# 第X章 …`（引擎用它做章标题）
- `@sub` 和 `@header` 各占一行，紧跟在标题后
- `@header` 决定页眉左格；不写就用「文件名前缀 · 首行标题」兜底

## 1. 七种容器

| 写法 | 用途 | 外观 |
|---|---|---|
| `:::goal 核心考点` | 章首目标，每章一个 | 淡蓝底 + 深蓝条 |
| `:::box 标题` | 正文主体块（国内考法、手算模板、小结） | 淡青底 + 墨绿条 |
| `:::note 降维注释` | 直觉解释、类比 | 米黄底 + 赭金条 |
| `:::warn 标题` | 易错点、陷阱 | 淡红底 + 砖红条 |
| `:::code` | 结构块：本章脉络、目录结构、纯文本流程 | 灰底，无标题，按缩进分层 |
| `:::flow 标题` | **可跨页**的长列表（题库专用） | 同 box |
| `:::quiz 【来源】编号 · 标题` | 题卡，三行固定 | 淡紫底 + 紫条 |

规则：

- 开标记 `:::类型 标题` 独占一行，**标题里可以带 `$公式$`**
- 结束标记是单独一行 `:::`（**不能省**，省了会把后面所有内容都吞进容器）
- `:::code` 没有标题，紧跟内容
- 长列表（超过 8 条）用 `:::flow`，否则整块会被推到下一页，留出半页空白

## 2. 题卡：三行固定

```markdown
:::quiz 【课后习题 1.1 第 6 题】反解组合系数
**题** 设 $\mathbf{v}=(1,-2,1)$、$\mathbf{w}=(0,1,-1)$，求 $c,d$ 使 $c\mathbf{v}+d\mathbf{w}=(3,3,-6)$。
**提示** 两个向量的分量之和都是 0，任何组合的分量之和也只能是 0。
**答案** $c=3,d=9$，三式自洽。
:::
```

- **来源标注必填**，写在标题里：`【课后习题 X.Y 第 N 题】`、`【教材例题 X.YZ】`、`【自拟】`
- 三行顺序固定：`**题**` → `**提示**` → `**答案**`；`**提示**` 可省，另两行必写
- 三个标签之间不要空行（空行会被拆成三段，题卡变高）

## 3. 公式

| 需求 | 写法 |
|---|---|
| 行内 | `$A\mathbf{x}=\mathbf{b}$` |
| 块级（独占一行居中） | `$$A\mathbf{x}=\mathbf{b}$$` |
| 矩阵 | `$$\begin{bmatrix}1&2\\3&4\end{bmatrix}$$`（`&` 分列，`\\` 分行） |
| 方程组 | `$$\begin{cases}2c-d=1\\-c+2d=0\end{cases}$$` |
| 分式 | `$\frac{a}{b}$`；根式写 `$\frac{1}{\sqrt{2}}$`，不要 `$1/\sqrt{2}$` |
| 并排两个公式 | `$$A=1\qquad B=2$$`（`\qquad` 会被转成 EM SPACE） |
| 增广矩阵 | 用 6 列 `bmatrix`，文字里注明"前 3 列是 $A$"——`array{ccc|ccc}` 的竖线会被转换器丢掉 |
| 共轭上划线 | `\bar{z}`（**上划线只盖紧邻的一个字符**）；要盖住整组才写 `\bar{z_1z_2}` |
| 共轭转置 | `A^{H}`；不用 `\overline`——它生成带水平线字符的 `m:acc`，Word 可能把线压到字母中间 |

**三条硬限制**：

1. 行内 `$...$` **不能跨行**，内部**不能出现第二个 `$`**（否则整行解析错位）
2. `\text{}` 只放 **≤4 字**的标签（`\text{可逆}`、`\text{第}i\text{行}`）；整句中文移到公式外
3. 公式里不要放矩阵以外的中文标点（逗号句号用正文写）

## 4. 表格

标准 Markdown，2–4 列：

```markdown
| 算法 | 写法 | 什么时候用 |
|---|---|---|
| 行·列 | $A$ 第 $i$ 行 · $B$ 第 $j$ 列 | 手算单个元素 |
```

- 列宽由引擎按列数固定分配（2 列 40/60，3 列 20/34/46，4 列 17/31/25/27）
- **单元格里不要放矩阵**（`\begin{bmatrix}` 会把行撑成 2–3 倍高，还会挤断中文），改写成"三行依次是 (1,0,0)…"

## 5. 标题层级与自动分页

| 写法 | 作用 |
|---|---|
| `# ` | 章标题，全篇一次 |
| `## ` | 节：`1.1 …`、`本章脉络`、`易错点与极客备忘录`、`附录 · 题库`、`一页速查` |
| `### ` | 小节 |

- `## 一页速查` 与 `## 附录 · 题库` 会**自动另起一页**（引擎硬编码），不用自己加分隔
- 速查卡必须是**最后一个** `## ` 块，且内容控制在一页内

## 6. 结构块（本章脉络）

```
:::code
向量 $\mathbf{v}=(v_1,v_2,\dots,v_n)$
├─ 运算 ── 逐分量
│   ├─ 加法 $\mathbf{v}+\mathbf{w}$
│   └─ 数乘 $c\mathbf{v}$
└─ 点积 $\mathbf{v}\cdot\mathbf{w}=\sum v_i w_i$
:::
```

引擎渲染时会**剥掉行首的 `│` `├` `└` `─`**，改成左缩进，层级如下算：

- `层级 = 本行前导竖线 │ 的个数 +（本行有 ├ 或 └ 则再 +1）`。所以 `├─` 一级、`│   ├─` 二级、`│   │    ├─` 三级，最多见到四层。
- 一级（含根）用主色加粗，二级以下常规字重——**缩进管层级、字重管主次**，不再靠画线。
- 纯竖线行（只有 `│`，用来画主干）会被丢弃，主干由缩进取代。
- **旧稿不用回改**：md 里继续写 `├─` `│` 就行，剥前缀是渲染时做的事。

写树的三条规矩：

1. **行内公式用 `$…$`**，正常排版；不要用 `sqrt(2)`、`eps`、`<=`、`=>`、`a_n` 这类 ASCII 近似（老稿已经这么写的，不强制回改）。
2. **树里禁堆叠分式**：`$…$` 里的 `\dfrac` / `\frac` / `x/2` 都会变成上下堆叠，把那一行撑高，整块缩进节奏立刻乱。要写分式就写成**不加 `$` 的纯文本** `a/b`（纯文本不走公式转换，不会被提升，lint 也不报）。
3. **树里禁 `\limits`**：`\lim_{n\to\infty}` 默认把下标放右侧，加 `\limits` 会挪到下方、同样撑高。直接写 `$\lim_{n\to\infty}$`。

`_{..}` / `^{..}` 老写法仍然有效（转成 Word 上下标）。**不要用 Unicode 的 `v₁`**——会渲染成逗号或空白。

## 7. 禁用清单（会被 lint 或视觉验收打回）

| 禁止 | 原因 | 替代 |
|---|---|---|
| `v₁`、`xᵢ`（U+2080 区） | Consolas 缺字形，显示成逗号 | `v1` 或 `v_{1}` |
| 行内 `$...$` 里放 `\begin{bmatrix}` | 行高变成邻行 2–3 倍 | 提到块级公式，或改文字描述 |
| `\text{整句中文}` | 中文与数学字体混排，公式行暴涨 | 移到公式外的正文 |
| `$$A=[\ldots]\quad B=[\ldots]$$` 里两个矩阵紧挨 | 括号会叠在一起 | 已由引擎插 1em，但仍建议拆成两条 |
| `\\[4pt]` 行距参数 | 会漏成字面文本 | 不加行距参数，靠默认 |
| 表格 / 题库里放矩阵 | 撑高行、挤断中文 | 文字描述 |
| 容器（`:::note`/`:::box`）内写 Markdown 表格 | 表格解析只在顶层做，容器内被压成一行竖线文本 | 移到容器外，或改写成散文并列句 |
| `\left| … \begin{bmatrix} … \end{bmatrix} … \right|` | 转换器抛 `ExtraLeftOrMissingRightError`，降级成红色 LaTeX 原文 | 行列式单独成块，正文补一句「取绝对值」 |
| `$|\det A|$` | 行内公式以 `|` 开头且含 `\det` 时 `\det` 被吞，渲染成「\| dA\|」 | 统一写 `$|A|$` |
| `\displaystyle` | 不被识别 | 行内直接省掉 |
| `\bigr)'(N)` 求导记法 | 转换后 `m:r` 为 0 | `\left(f^{-1}\right)'(N)` |
| `\big\vert` / `\Big\vert` 带上下标 | 漏成字面 `\vert` | 改代入求值写法 |
| `\bar{z_j}`（上划线包住下标） | 线会盖到下标上，看着像 $z$ 和 $j$ 都带线 | `\bar{z}_j`；`\bar{z_1z_2}` 是"盖整组"的正当写法，别一起改 |
| `\overline{z}` | 生成带水平线字符的 `m:acc`，Word 可能把线压到字母中间 | `\bar{z}` |

> `\operatorname{…}` 曾列在本表里（「转换失败」），11-11 复测线代 4 册共 19 处，`document.xml` 里都以正体 `rank`/`tr` 正常转出、`audit` 报转换失败 0，**该条已证伪并移除**。新稿仍建议写 `\mathrm{…}` 与既有各册保持一致。

## 8. 写完自检

```bash
# md 前置检查（构建前必跑，ERROR 清零）
python "<skill>\scripts\复习资料_lint_md.py" <md>

# 线性代数额外：记号规则
python "<skill>\scripts\lint\线性代数_lint.py" <md>

# 构建 + 页数（超 15 页会标出来）
python "<skill>\scripts\复习资料_重建.py" 线性代数 --pdf
```

`lint` 的 ERROR 必须为 0；WARN（「正文未写记号框」）属正常，构建时会从 `<科目>_notation.md` 自动注入。

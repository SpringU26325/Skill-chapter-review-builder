# 自检与视觉验收（Step 2 读这一份）

> **什么时候读**：md 写完、docx 构建之后，交付之前。

## 一、六项自检（缺一不可）

交付时随文档附**自检报告**：写在对话回复里（六项逐条给结论，用表格），**不单独出 md 文件**；不接受「已检查」这种空话。

| # | 项 | 怎么算过 |
|---|---|---|
| 1 | **覆盖度** | 素材定位与覆盖（PDF 物理页 / 课件 `pNN` / 文件+节号；非 PDF 素材用「来源清单 + 覆盖对照表」代替页码范围）、每节对应关系、方框/例题/关键图的吸收情况用表格列出；**知识点 ↔ 题目对应表**（逐知识点列出所配题目及来源，任何知识点无题即为不合格）。工作区追加要求并入本项核对，有偏差时单列 |
| 2 | **准确度** | 哪些数值逐页核对过；哪些是**自行推导**（必须明说，如「主干只给结果，输入是反解出来的」）；模糊处是否标 `[疑似: xxx]` |
| 3 | **公式语法** | 构建前先跑 md 前置检查（ERROR 清零再构建）；构建日志里「公式失败」必须为 **0 处**（非 0 说明该公式在成品里是空白或原始 LaTeX，`重建` 会把这类册子标 `OK*`）；构建后跑审计——转换失败为 0，四项硬指标全过，结构计数（`m:d`/`m:m`/`m:eqArr`）附在报告里；`<科目>_lint.py` 存在时另跑，**ERROR 为 0** |
| 4 | **交叉引用** | grep 所有 `(x.y)`、`式 (x)`、`例 x.y`、`见§x`，逐个确认**本册内有对应本体且编号一致**；悬空引用为 0 |
| 5 | **视觉验收** | 全量页数 / 空页筛查 + **关键页逐页看图**（首页、含矩阵或表格页、题卡页、速查卡；引擎或容器类型改动后改全量逐页看）。**有图的册子另看三件：图不糊（放大看箭头与字母边缘）、图与图注不跨页、图没被版心裁掉**。只看脚本指标不算通过——字体计数、残留扫描可以全过，公式照样挤成一团 |
| 6 | **排版逻辑** | 页数落在 8–15 页（>15 必须拆）；字数、层级、配色是否一致；已知取舍主动交代（如「为保证速查卡不被腰斩，末页留白 40%」） |

命令见 `SKILL.md` 的命令速查。审计脚本报的是**四项硬指标**：

1. `w:drawing` 个数**等于** md 图片引用数（`word/media` 可少于引用数，同图复用会去重）；`w:pict`/`w:object` 仍须为 0 —— 公式必须是 OMML，不能是截图
2. `Cambria Math` 出现次数 ≈ `m:r` 个数 —— 每个公式 run 都指定了数学字体
3. `m:t` 里 U+1D400–U+1D7FF 字符数为 0 —— Unicode 数学字母已归一化
4. `m:t` 里 `\`、`$` 为 0，NBSP 为 0 —— 没有 LaTeX 源码或假换行漏进公式（`\qquad` 用 EM SPACE U+2003 撑开，属正常排版，不计入违规）

## 二、视觉验收流程（强制）

前四项是「文本层」检查，**查不出视觉问题**，必须补这一步。

1. **转 PDF 报页数**：用重建脚本的 `--pdf`（默认增量，一个 Word 实例内串行、带锁，直接报页数并标出超 15 页的；**只有改过引擎才加 `--all`**）。**并行会话里必须用 `--only <章节名>`**——科目关键字是子串匹配，「程序设计」会把该科所有章一起重出，连别人正在改的那册也重写。看图另走渲染脚本三段（`--prepare` → PowerShell 执行 `render.ps1` → `--render`）。**复查复用同一实例**，不要每改一行就手工新建一个 `Word.Application`——反复起停会累积自动恢复残留。
2. **空页筛查 + 渲染**：先用 pymupdf 打印每页文字长度，出现 `len<40` 的页即容器整块换页造成的空页（删 1–2 行正文或题库题补回余量，**不要缩字号压行距**）；再用 `page.get_pixmap(dpi=140)` 出全页图；可疑处 `dpi=300` + `clip` 裁切放大（判断括号是否包住全部行时 140 不够）。
3. **关键页逐页看**（一次读一张图，每张问「这页有什么不对」）：至少覆盖首页、含矩阵 / 表格页、任一张题卡页、速查卡页；**改过构建引擎或新增容器类型时改为全量逐页看**。按此顺序，漏一项就算没查：
   - **公式**：字形是否数学字体、上下标是否完整、**相邻矩阵有无间距**、括号是否包住全部行、行内矩阵有没有撑高行
   - **结构块（本章脉络）**：缩进层级是否连续（1→2→3 层，不跳级）、分式是否真的横线（不是斜杠）、矢量是否加粗、导数点是否贴在字母上（飘到上方就是引擎回退到旧版）、每行是否只并排了一个分式、有没有残留 ASCII（`*`、`^`、`pi`、`alpha`、`w` 当 ω）、有没有一条近半行长的横线（`────────` 未缩短）
   - **题卡**：题/提示/答案三行是否清晰，中文有没有被公式挤断
   - **表格**：各行高度是否一致、列宽是否挤压
   - **速查卡**：标签与公式是否同行、卡片是否完整（没被分页切开）
   - **页眉页脚**：左右是否分列、页码是否连续
   - **空白**：有没有超过 1/3 页的异常留白（九成是容器整块换页）
4. **分两类处置**：
   - **引擎级**（间距、字体、行距、解析）→ 改 `scripts\复习资料_build.py`，改完**所有已交付章节必须重建**；
   - **内容级**（矩阵写错、符号反了、文字挤断）→ 改对应 md。
5. **复查**：改完**重新渲染同一页再看一遍**，不能改完直接交。
6. **回填**：新踩的坑先记 `复习资料\_生产\_踩坑清单.md`，能规则化的再落成 `scripts\复习资料_lint_md.py` 的一条规则。不写下来，下一章必犯。

## 三、空页与留白

- `len<40` 的页即疑似空页，九成是容器整块换页：删 1–2 行正文、或补一道题把余量填回。
- **绝对不许**靠缩字号、压行距假装达标。
- 三条留白经验：大 box（>半页）按主题拆成两个小 box；代码块压到 14 行内，否则被切成两截；速查卡前的附录页若只剩几行，**加题**补满而不是删内容。

## 四、篇幅与拆册判据

舒适区 8–12 页，硬上限 15 页，超过必须拆。页数以 Word COM `ComputeStatistics(2)` 实测为准，**不按字数换算**。

`python-docx` 写出的 docx，`docProps/app.xml` 里的 `<Pages>` 恒为 1，**不是真实页数**——别拿它当证据。只有 `复习资料_页检.py` 或重建脚本 `--pdf` 走 COM 报出来的数才算。

**先按单册做**，触发拆册的条件有两个：

1. 成品超 15 页；
2. **素材层级**（主干内容 / 课堂扩展内容需要分册）。

原文页数只作预警（>50 页先按两份规划），**不是硬判据**——原文 53 页若成品 12 页就不该拆；原文 40 页若配题多、成品 17 页，照样得拆。

切点选在「某一节讲完后成品接近 12 页」处，并提前告知方案。**拆后每册仍应 ≥8 页**；若按素材层级触发但内容不足，把扩展并入下册选讲节，不单独成册。

### 拓展册（该章确有课堂扩展素材时）

- **一章一份，不跨章合订**：`<科目>_第X章拓展_复习资料.docx`，独立 goal / 本章脉络 / 题库 / 一页速查，8–12 页。
- **内容口径**：只收课件 `*` 标注与绪论点名的扩展，定位「进阶结论 + 国内考法 + 压轴题」；**不重讲上/下册已有的推导**，`:::goal` 第一段必须写明与上下册的分工（如「推导见下册 §3.6，这里只做变式与硬题」）。
- **没素材就不做**：该章课堂确无扩展内容时只交主干册，不硬凑第三册。
- 超 15 页说明塞进了主干内容，回头砍到强化题为止。

## 五、跳转与导航（引擎 1.1.0 起）

构建日志会打印一行 `跳转: 标题书签 N | 速达 N | 脉络链接 N | 题目链接 N | 附录条目 N/N`，交付前照此核对：

1. **速达**：首页应有 2–4 项，全部可点（本章脉络 / 易错点 / 题库 / 一页速查）。
2. **脉络链接**：「未连接 N 条」若与子条目数相当（「推论：…」「唯一性定理：…」这类），正常；若一级小节行大量未连，说明标题写法与脉络行差异过大，回查。
3. **题目链接**：2.4.1 起正文题按所在节进索引（`【自拟】` 等白名单前缀即可，不要求节号），附录题仍需 `【课后习题 6.5 第 1 题】` 或 `【真题 §6.5 …】` 才能跨节挂靠。`【习题 3.1】`（题号）不算节号。整册一个链接都没有，多半是缺 `## 附录 · 题库`（`appx` 开关只认这个标题），`lint` 报 ERROR；若个别节仍无题，`lint` 2.4.1 起按节报 ERROR（全源稿实测仅 3 处真空节）。
4. **打开 docx 抽查**：点一条脉络行、点一个小节下的题号，确认落点正确——不只看有没有链接，要看跳到的是不是那一节。Word 左侧导航窗格应显示三级标题，标题左侧出现折叠三角。
5. **链接与版式**：正文题纳入索引后，此前题目链接为 0 的册子会新增「对应题目」行（程序设计_第1章实测 0→14、11→12 页）。这是补回本该有的导航信息，不是回跳多占行——回跳始终挂在既有题目行尾，不另起段落。
6. **标题不与正文分家**：每个二级标题应与它的「对应题目」行、以及紧随的正文同页。标题留在页底、正文翻页即为缺陷（`keep_with_next` 链被插入段落截断），v1.1.1 起该行自带 `keepNext`；批量核对可用 Word COM 逐段比较 `OutlineLevel=2` 段与其下一正文段的 `Information(3)` 页号。
7. **折叠按钮**：正文标题左侧的折叠三角只在段落使用内置 `标题 1/2/3` 样式时出现。若只看得到导航窗格、看不到折叠按钮，先查段落样式是不是仍是「正文」。

# md 方言完整手册（写 md 时随时查）

> **什么时候读**：写 md 正文时对照；容器、公式、表格与禁用清单都在这一份里。

源稿是 Markdown，由构建引擎转成 docx。**容器名、标记格式写错不会报错，只会静默变成普通段落**，所以这份手册要照着抄。

> **标 ✅ 的节不用背**：`复习资料_lint_md.py` 会自动拦，写完跑一遍就知道错在哪、怎么改。
> 只有标 ◐（部分拦）和 ⚠（只能人看）的才需要事先照着写。
> 已完全覆盖：文件骨架、七种容器、题卡三行、图片行、标题层级与速查收尾、结构块树规则、
> 公式的 `$$` 三坏形态、禁用清单里的矩阵简写 / `\underline` / 围栏代码块 / 附录结构 / 每节有题。
>
> 这一版把「写前必读」降级成「出错时的解释手册」：`lint` 报 ERROR / WARN 时，按它给的行号回这一节查「为什么」和「改成什么」。**不要为了写稿先把整份读完。**

## 0. 文件骨架 ✅

```markdown
# 第X章 章节名

@sub 科目 · 主干资料名 · 单位 pA–B
@header 科目 · 第 X 章  章节名

:::goal 核心考点
一两句话说清"这章在解决什么问题"，再列考试落点。
:::

## 本章脉络 ⚠

:::code
根 $\mathbf{v}=(v_1,\dots,v_n)$
├─ 分支一 ── 一句话点明它归属于哪一节
│   ├─ 条目的关键式子 $\sqrt{2}$
│   └─ 另一条
└─ 分支二
:::
```

- `@sub` 写**本册实际主干**：教材是「教材名 第N版 · 原书 pA–B」；课件是「课件第 X 章 · pA–B」（幻灯片号，不是教材页码）；题库或讲义写书名/文件名 + 自己的编号单位。**不许编页码**，主干没有页码就只写来源名。
- 第一行必须是 `# 第X章 …`（引擎用它做章标题）
- `@sub` 和 `@header` 各占一行，紧跟在标题后
- `@header` 决定页眉左格；不写就用「文件名前缀 · 首行标题」兜底

## 1. 七种容器 ✅

| 写法 | 用途 | 外观 |
|---|---|---|
| `:::goal 核心考点` | 章首目标，每章一个 | 淡蓝底 + 深蓝条 |
| `:::box 标题` | 正文主体块（国内考法、手算模板、小结） | 淡青底 + 墨绿条 |
| `:::note 降维注释` | 直觉解释、类比 | 米黄底 + 赭金条 |
| `:::warn 标题` | 易错点、陷阱 | 淡红底 + 砖红条 |
| `:::code` | 结构块：本章脉络、目录结构、纯文本流程 | 灰底，无标题，按缩进分层 |
| `:::flow 标题` | **可跨页**的长列表（题库专用） | 同 box |
| `:::quiz 【来源】编号 · 标题` | 题卡，三行固定 | 淡紫底 + 紫条 |

规则：

- 开标记 `:::类型 标题` 独占一行，**标题里可以带 `$公式$`**
- 结束标记是单独一行 `:::`（**不能省**，省了会把后面所有内容都吞进容器）
- `:::code` 没有标题，紧跟内容
- 长列表（超过 8 条）用 `:::flow`，否则整块会被推到下一页，留出半页空白

## 2. 题卡：三行固定 ✅

```markdown
:::quiz 【课后习题 1.1 第 6 题】反解组合系数
**题** 设 $\mathbf{v}=(1,-2,1)$、$\mathbf{w}=(0,1,-1)$，求 $c,d$ 使 $c\mathbf{v}+d\mathbf{w}=(3,3,-6)$。
**提示** 两个向量的分量之和都是 0，任何组合的分量之和也只能是 0。
**答案** $c=3,d=9$，三式自洽。
:::
```

- **来源标注必填**，写在标题里：`【课后习题 X.Y 第 N 题】`、`【教材例题 X.YZ】`、`【自拟】`
- 三行顺序固定：`**题**` → `**提示**` → `**答案**`；`**提示**` 可省，另两行必写
- 三个标签之间不要空行（空行会被拆成三段，题卡变高）

## 3. 公式 ◐

| 需求 | 写法 |
|---|---|
| 行内 | `$A\mathbf{x}=\mathbf{b}$` |
| 块级（独占一行居中） | `$$A\mathbf{x}=\mathbf{b}$$`——**`$$` 与公式必须在同一行**，整行不放正文（2.7.9 起 lint 对孤行 `$$`、未在本行闭合的 `$$`、行中 `$$` 都报 ERROR） |
| 矩阵 | `$$\begin{bmatrix}1&2\\3&4\end{bmatrix}$$`（`&` 分列，`\\` 分行） |
| 方程组 | `$$\begin{cases}2c-d=1\\-c+2d=0\end{cases}$$` |
| 分式 | `$\frac{a}{b}$`；根式写 `$\frac{1}{\sqrt{2}}$`，不要 `$1/\sqrt{2}$`。**`/` 只留给单位，其余一律 `\frac`**——判据与反例见下方「除法只有一个写法」 |
| 单位 | `$\mathrm{m/s}$`、`$\mathrm{m/s^{2}}$`——**斜杠形式，不堆叠成分数线**；单位整体包一层 `\mathrm{…}`，不要拆成 `\mathrm{m}/\mathrm{s}`（拆开后正体标记丢失，字母会变斜体） |
| 并排两个公式 | `$$A=1\qquad B=2$$`（`\qquad` 会被转成 EM SPACE） |
| 极限 | `$\lim_{\Delta t\to0}\dfrac{\Delta s}{\Delta t}$`——照写 `\lim_{…}`，引擎排正体并把极限压到正下方；不用写 `\limits`，也不用包 `\mathrm` |
| 其他算子 | `$\sin x$`、`$\ln x$`、`$\log_{2}x$`、`$\max a_i$` 照写，引擎统一排正体。**`\exp` 不在其中**——见下一行 |
| 指数 | 一律 `e` 上标：块级 `$$p=p_0e^{-\frac{Mgh}{RT}}$$`，行内短指数 `$n=n_0e^{-mgh/kT}$`。**不要写 `\exp(…)` 这种算子形式**——`\exp` 会被排成正体 `exp` 再跟一对括号，印出来是 `exp(−mv²/2kT)`，与教材的「e 的右上角」不是一回事。**行内指数里的斜杠是「除法一律 `\frac`」的唯一例外**（单位不算除法，另有规定），理由见下方「指数只有一种写法」 |
| 增广矩阵 | 用 6 列 `bmatrix`，文字里注明"前 3 列是 $A$"——`array{ccc|ccc}` 的竖线会被转换器丢掉 |
| 共轭上划线 | `\bar{z}`（**上划线只盖紧邻的一个字符**）；要盖住整组才写 `\bar{z_1z_2}` |
| 线段 / 弦长标记 | `$\bar{BC}$`——`\bar` 会拉宽盖住整组；**不要 `\overline{BC}`**，它是破折号字形，线会从字母中间穿过 |
| 绝对值 | `$\left|\left(\Delta\mathbf{v}\right)_n\right|$`——绝对值里的括号也写成 `\left(…\right)`；裸 `(` 会被当定界符分隔符，砸出一个空槽（成品里 `\|` 与内容之间空一块） |
| 共轭转置 | `A^{H}`；不用 `\overline`——它生成带水平线字符的 `m:acc`，Word 可能把线压到字母中间 |

**除法只有一个写法：`\frac`，单位除外。**

转换器只在 `mrow` **恰好三个子元素**、且这一处除法独占整条公式时才折成分数线。同一条公式里再有一个 `=`、`+`、`\geqslant`，就超过三项，`/` 落成一个普通字符——Cambria Math 的实心斜杠跨整个字身，紧跟带上下标的量时看着就像压在下标上。实测（`\gamma=5/3` 这类是作者最常写的形态，全是斜杠）：

```
\gamma=5/3          → 斜杠        \frac{5}{3}         → 分数线
T/T_0=1             → 斜杠        \frac{T}{T_0}       → 分数线
mv_\theta^{2}/l     → 斜杠        \frac{mv_\theta^{2}}{l} → 分数线
p=\nu RT/V          → 斜杠        \frac{\nu RT}{V}    → 分数线
\mathrm{d}s/\mathrm{d}t → 斜杠    \frac{\mathrm{d}s}{\mathrm{d}t} → 分数线
```

所以：

- 比值、导数、商**一律 `\frac`**，包括看起来「简单」的：`$\frac{mv_\theta^{2}}{l}$`、`$\frac{\nu RT}{V}$`、`$\frac{p_1-p_0}{p_0}$`、`$\frac{5}{3}$`、`$\frac{T}{T_0}$`、`$\frac{1}{\mu_s}$`。不要用 `/` 赌它能折。
- 斜杠合法出现的地方只有两处：**单位**（`$\mathrm{m/s}$`、`$\mathrm{kg\cdot m/s^{2}}$`，整段包在 `\mathrm{}` 内，引擎判成正体、保留斜杠字形）与**行内指数**（`$e^{-mgh/kT}$` 里的斜杠是刻意留的——上标字号只有正文七成，写 `\frac` 会压到 3–4 pt，理由见下方「指数只有一种写法」）。其余一律 `\frac`。
- 行内竖排分数会把那一行抬到约 1.5 倍行高：一行里只放一个分式，挤不下就拆行或把该式提成块级（第 6 节「写树的五条规矩」第 2 条）。

**指数只有一种写法：`e` 加右上角上标，不用 `\exp`。**

`\exp` 是 LaTeX 的算子名，引擎会把它排成正体、后面那对括号原样保留——成品是 `exp(−mv²/2kT)`，教材要的是 `e` 的右上角，两者不是一回事（9 章下 9.9 节的 f(v) 就是这么印出来的）。

但上标里的字号已经缩到正文的七成，再套一层 `\frac` 会压到 3–4 pt。实测（同一套引擎、420 dpi 导出）：

```
块级  $$p=p_0e^{-\frac{Mgh}{RT}}$$          → 小分式，能读，与教材同形
行内  $n=n_0e^{-\frac{mgh}{kT}}$            → 分数线与字母几乎粘在一起，糊
行内  $n=n_0e^{-mgh/kT}$                    → 斜杠，字大清楚
行内  $n=n_0e^{-mgh/(kT)}$                  → 斜杠带括号分母，同样不折，清楚
```

所以分场景：

- **块级独立公式用分式**：`$$f(v)=4\pi\left(\frac{m}{2\pi kT}\right)^{3/2}v^2e^{-\frac{mv^2}{2kT}}\qquad v\ge 0$$`。成行居中、字号够，小分式还读得出。
- **行内一律斜杠**：`$n=n_0e^{-mgh/kT}$`。`-mgh/kT` 是四项式，转换器不会折成 `m:f`，斜杠原样保留；写成 `e^{-mgh/(kT)}` 也行（分母带括号，同样不折）。
- **唯一例外**：指数部分长到上标装不下、又必须留在行内（如 9 章下第 106 行 `$\exp\left[\frac{(M_{\mathrm{O_2}}-M_{\mathrm{N_2}})gh}{RT}\right]$`）。用了就得接受它印成 `exp(…)`；这种情况 lint 仍会报 WARN，属于明知故犯，不必改。

**三条硬限制**：

1. 行内 `$...$` **不能跨行**，内部**不能出现第二个 `$`**（否则整行解析错位）
2. `\text{}` 只放 **≤4 字**的标签（`\text{可逆}`、`\text{第}i\text{行}`）；整句中文移到公式外
3. 公式里不要放矩阵以外的中文标点（逗号句号用正文写）

## 4. 表格 ◐

标准 Markdown，2–4 列：

```markdown
| 算法 | 写法 | 什么时候用 |
|---|---|---|
| 行·列 | $A$ 第 $i$ 行 · $B$ 第 $j$ 列 | 手算单个元素 |
```

- 列宽由引擎按列数固定分配（2 列 40/60，3 列 20/34/46，4 列 17/31/25/27）
- **单元格里不要放矩阵**（`\begin{bmatrix}` 会把行撑成 2–3 倍高，还会挤断中文），改写成"三行依次是 (1,0,0)…"

## 4b. 图片（示意图形） ✅

只在「内容本身就是一张图」时用：流程图符号、结构框图、受力图、波形图、几何示意。表格照上面写成 md 表，公式走 `$$…$$`，两者都不进图片通道。

```markdown
![图 3.18　例 3.12 用图](figures/大学物理/第3章_例3.12_球在纸上.png){w=6.4}
```

- **独占一行**。夹在连续段落中间会被 `flush()` 拼进正文，变成一行字面上的 `![…](…)`。
- 路径按 md 所在目录解析：源稿平铺在 `_源稿\`，所以前缀是 `figures/<科目>/`。文件名不要带括号。
- `{w=6.4}` 可省。省略时按「像素 ÷ 300dpi × 2.54」还原原书尺寸，夹在 3–16.6cm；只有外部截图才需要手写。
- 图注必填，原样输出为 8pt 小字，紧贴图下。编号手写（`图 3.18`），引擎不自动编号。
- 图只裁图形，**不要把教材上的图注或说明文字一起裁进来**——文字留在文字层才可搜、可缩放。
- 可放在正文顶层、`:::box` 一类容器内、`:::quiz` 题卡内三处。

## 5. 标题层级与自动分页 ✅

| 写法 | 作用 |
|---|---|
| `# ` | 章标题，全篇一次 |
| `## ` | 节：`1.1 …`、`本章脉络`、`易错点与极客备忘录`、`附录 · 题库`、`一页速查` |
| `### ` | 小节 |

- `## 一页速查` 与 `## 附录 · 题库` 会**自动另起一页**（引擎硬编码），不用自己加分隔
- 速查卡必须是**最后一个** `## ` 块，且内容控制在一页内

标题还会自动获得大纲级别（`#`→1、`##`→2、`###`→3），Word 左侧导航窗格按层级显示，标题左侧可折叠。以下三处跳转由引擎自动生成，**源稿不需要写任何标记**：

| 位置 | 点它去哪 | 判定依据 |
|---|---|---|
| 首行「速达」 | 本章脉络 / 易错点 / 题库 / 一页速查 | `## ` 标题名精确匹配，缺哪块就不出哪项 |
| 本章脉络的每一行 | 对应小节的标题 | 同名 → 同编号（`§6.5` 对 `6.5 …`）→ 标题主干被包含，逐级放宽；命中不唯一时不连 |
| 小节标题下的「对应题目」 | 本节的题（正文优先）+ 附录里挂本章的题 | 正文题按**所在节**自动挂靠，标签写 `【自拟】` 即可；附录题需 `【课后习题 6.5 第 1 题】` 取 `6.5` 或 `【真题 §6.5 …】` 显式 `§`。只有前缀为自拟/课后习题/教材例题/课堂例题/真题/思考题/总复习题的标签才算题 |

- **脉络首行是树的根，默认连到章标题。** 若首行本身就是节名（带 `§6.5` 或 `（2.5）`），会连到那一节；这适用于「整棵树从某一节开始、没有根行」的写法，正文完整的一章不要这么写。
- 附录书签靠 `【…】` 标签识别，标签必须写在条目开头；`【习题 3.1】` 这种是题号不是节号，不参与题目跳转。
- **每节至少一道题**（`SKILL.md` 硬约束 3）：正文写 `:::quiz 【自拟】标题` 或 `- **【自拟】** 题干…`，附录题靠 `§X.Y` 挂靠。整节无题时该节不出「对应题目」行、也没有回跳，`复习资料_lint_md.py` 报 ERROR。
- 脉络行连不上就保持纯文本，不报错；构建日志给出「未连接 N 条」，接不上的都是子条目（如「推论：…」），属正常。

## 6. 结构块（本章脉络） ✅

```
:::code
向量 $\mathbf{v}=(v_1,v_2,\dots,v_n)$
├─ 运算 ── 逐分量
│   ├─ 加法 $\mathbf{v}+\mathbf{w}$
│   └─ 数乘 $c\mathbf{v}$
└─ 点积 $\mathbf{v}\cdot\mathbf{w}=\sum v_i w_i$
:::
```

引擎渲染时会**剥掉行首的 `│` `├` `└` `─`**，改成左缩进，层级如下算：

- `层级 = 本行前导竖线 │ 的个数 +（本行有 ├ 或 └ 则再 +1）`。所以 `├─` 一级、`│   ├─` 二级、`│   │    ├─` 三级，最多见到四层。
- 一级（含根）用主色加粗，二级以下常规字重——**缩进管层级、字重管主次**，不再靠画线。
- 纯竖线行（只有 `│`，用来画主干）会被丢弃，主干由缩进取代。
- **旧稿不用回改**：md 里继续写 `├─` `│` 就行，剥前缀是渲染时做的事。注意这句只指「不用把树符删掉、改成空格」——反过来把 `│` 删成空格是要修的，见下面第 4 条。

写树的五条规矩：

1. **树块里的公式用 `$…$` 写 LaTeX**（11-18 起）。分式 `\dfrac{\mathrm{d}v}{\mathrm{d}t}`、矢量 `\mathbf{v}`、角速度 `\boldsymbol{\omega}`、导数 `\dot r` / `\ddot r`、单位矢量 `\hat r`，照正文那套写。代价是两点，都接受：字体从等宽跳成 Cambria Math；含分式的行比邻行高出约一半——**行高不必齐**，11-18 定过。
   **单位矢量的导数照写 `\dot{\hat r}`**：引擎会把窄的点换到帽里层（`\hat{\dot r}` 同形），因为 Word 的叠加重音只有这个排法不飘，见 `engine.md`。
   **裸 ASCII 一定不行**：`f_u`、`d^2`、`v^2/R`、`w`、`d0/dt`、`2*pi/w`、`er`、`w x r`、`=>` 会**原样进 Word**——11-18 第 1 章下的脉络块就是这么印出来的，`ω` 变成 `w`、`θ` 变成 `0`，整块公式是错的。`lint_md` 对树块内裸 `x_y` 报 WARN。
   **旧稿不用回改**：已经写成 Unicode 纯文本（`ω = dθ/dt`、`aₙ`）的树块照旧能渲染，但新写的按本条走。
2. **一行只放一个分式**。两个 `\dfrac` 并排会把那一行抬到邻行的两倍高，那种参差就没法看；第二个分式拆到下一行。`lint_md` 对一行 ≥2 个 `\dfrac` 报 WARN。树里也不要写斜杠：只有整条公式就是 `$a/b$` 这一处除法时转换器才折成分数线，行里再有一项（`=`、`+`）就退化成一条压着下标的斜杠，所以树块里一律写 `\frac`，判据见第 3 节分式条。
3. **树里禁 `\limits`**：`\lim_{n\to\infty}` 默认把下标放右侧，加 `\limits` 会挪到下方、同样撑高。直接写 `$\lim_{n\to\infty}$`。
4. **子项必须带 `│`，空格不算层级**。层级只看前导 `│` 个数与分支符，缩进几个空格对引擎没有意义。`└─` 父行的子项也要补 `│`，不能写成纯空格缩进——`    ├─` 数到 0 个 `│`，仍是 1 级，渲染出来与父行同缩进、同加粗。正确写法 `│   ├─`（2 级）、`│   │   ├─`（3 级）。`lint_md` 对此报 ERROR（1.1.2 起）。
5. **节名与要点之间的分隔横线写 `──`（两个），不要拉长对齐**。`────────` 是等宽编辑器里手打对齐的产物，进 Word 后字号字距都变，会成一条突兀的长横线、占掉半行。两个短横够用，层级已由缩进表达。`lint_md` 对树块内 ≥3 个连写 `─` 报 WARN。

`_{..}` / `^{..}` 老写法仍然有效（转成 Word 上下标）。**正文里不要用 Unicode 下标**（`v₁` 在中文字体里会渲染成逗号或空白），正文要下标写 `$v_1$`；树块里的旧稿允许保留（历史写法），新稿优先 `$a_n$`。

## 7. 禁用清单（多数已由 lint 自动拦）

| 禁止 | 原因 | 替代 |
|---|---|---|
| `v₁`、`xᵢ`（U+2080 区） | Consolas 缺字形，显示成逗号 | `v1` 或 `v_{1}` |
| 行内 `$...$` 里放 `\begin{bmatrix}` | 行高变成邻行 2–3 倍 | 提到块级公式，或改文字描述 |
| `\text{整句中文}` | 中文与数学字体混排，公式行暴涨 | 移到公式外的正文 |
| `$$A=[\ldots]\quad B=[\ldots]$$` 里两个矩阵紧挨 | 括号会叠在一起 | 已由引擎插 1em，但仍建议拆成两条 |
| `\\[4pt]` 行距参数 | 会漏成字面文本 | 不加行距参数，靠默认 |
| 表格 / 题库里放矩阵 | 撑高行、挤断中文 | 文字描述 |
| 容器（`:::note`/`:::box`）内写 Markdown 表格 | 表格解析只在顶层做，容器内被压成一行竖线文本 | 移到容器外，或改写成散文并列句 |
| 三个反引号的围栏代码块 | **引擎只认 `:::code`**：围栏行变成普通段落，代码各行被空格拼成一整段流水文本，缩进/注释/换行全丢，而 lint 与 audit 都是绿的 | `:::code` … `:::`，块内保留原缩进 |
| `:::code` 嵌在 `:::box`/`:::quiz` 里 | 容器内第一个 `:::` 被当结束符，内外层级错位 | 移到容器外，正文用一句话引出 |
| 孤行 `$$`（`$$` 单独占一行，公式夹在下一行） | 引擎逐行解析，`strip('$')` 得到空串：产出空公式、公式内容降级成正文文本，audit 因 `re.S` 跨行匹配反而认为合法 | 全部写在同一行：`$$…$$` |
| 行中 `$$x^2$$`（句子中间） | 只从第二个 `$` 起配对，前后各剩一个孤儿 `$` 印进正文 | 句中公式用 `$…$`；显示公式独占一行 |
| 树块里裸写 `f_u` / `z_x` / `d^2` | 不渲染，原样变普通文本，整块脉络看着像纯文字（11-15 第 6 章中实测） | 包成 `$f_u$`、`$z_x$`、`$d^2$` |
| `\left| … \begin{bmatrix} … \end{bmatrix} … \right|` | 转换器抛 `ExtraLeftOrMissingRightError`，降级成红色 LaTeX 原文 | 行列式单独成块，正文补一句「取绝对值」 |
| `$|\det A|$` | 行内公式以 `|` 开头且含 `\det` 时 `\det` 被吞，渲染成「\| dA\|」 | 统一写 `$|A|$` |
| `\displaystyle` | 不被识别 | 行内直接省掉 |
| `\bigr)'(N)` 求导记法 | 转换后 `m:r` 为 0 | `\left(f^{-1}\right)'(N)` |
| `\big\vert` / `\Big\vert` 带上下标 | 漏成字面 `\vert` | 改代入求值写法 |
| `\bar{z_j}`（上划线包住下标） | 线会盖到下标上，看着像 $z$ 和 $j$ 都带线 | `\bar{z}_j`；`\bar{z_1z_2}` 是"盖整组"的正当写法，别一起改 |
| `\overline{z}`、`\overline{BC}` | `latex2mathml` 输出 `<mo>U+2015</mo>`（HORIZONTAL BAR 破折号字形），MML2OMML 又当重音字符塞进 `m:acc`——那个字形本就排在字高中部，Word 不会把它抬成上划线，成品是一道**穿过字母的删除线**（11-18 第 1 章下实测） | `\bar{z}`、`\bar{BC}`：走 `m:bar`，Word 自己画的线，位置正确、宽度跟内容 |
| `|(\Delta\mathbf{v})_n|`（绝对值里夹裸括号） | latex2mathml 把 `_n` 挂在 `)` 上，MML2OMML 于是把 `(` 当定界符的**分隔符** `m:sepChr`，拆出两个参数槽、第一个是空的：成品里 `\|` 与内容之间空一块，Word 编辑态显示成虚线占位框 | 内层括号也写 `\left(\Delta\mathbf{v}\right)`，整串 `\left|\left(\Delta\mathbf{v}\right)_n\right|` |
| `$[[1,0.2],[0,0.8]]$`（矩阵简写） | 引擎只认 `\begin{bmatrix}`。`[[ ]]` 被当普通字符平铺，成品是 `[1,0.2],[0,0.8]`；两个相邻矩阵还粘连成 `[0,0.8][0.2,1]`。构建与 audit 都不报 | 块级 `$$\begin{bmatrix}…\end{bmatrix}$$`，或改文字描述 |
| `\underline{…}`（填空横线） | `latex2mathml` 一律输出 `munder`，引擎不支持，整段公式在成品里为空；不报错时只剩一句「$\mathbf{v}=$」 | 填空写在数学外，直接 `____` |
| `\exp\left(-\frac{mv^2}{2kT}\right)` | `\exp` 是算子名，引擎排成正体 `exp` 再跟括号，成品是 `exp(−mv²/2kT)`；教材是 `e` 的右上角（9 章下 9.9 节 f(v) 实测）。9 章下现存 9 处、另 4 份源稿 6 处（合计 5 份、15 处），lint 记 WARN | 块级 `$e^{-\frac{mv^2}{2kT}}$`，行内短指数 `$e^{-mv^2/kT}$`；理由与实测见第 3 节「指数只有一种写法」 |

> **结构硬要求**：有 `:::quiz` 的册子必须有 `## 附录 · 题库`，且附录区内有 `【…】` 条目。引擎的 `appx` 开关只认含「附录 / 题库」的二级标题，缺了它 `_qmap` 恒空——各节的「对应题目」行与题卡的 `_Q` 书签全部不生成，构建只打印「题目链接 0」，既不报错也不失败。lint 2.2.2 起报 ERROR。

> `\operatorname{…}` 曾列在本表里（「转换失败」），11-11 复测线代 4 册共 19 处，`document.xml` 里都以正体 `rank`/`tr` 正常转出、`audit` 报转换失败 0，**该条已证伪并移除**。新稿仍建议写 `\mathrm{…}` 与既有各册保持一致。

# 补充资料：类型清单与转换通道

> **按需读**。只有在①遇到 `intake.md` 第二节表里没有的后缀，或②需要具体转换命令时才打开本文件。
> 本文件是清单，不是流程；流程、可信度判定、定位单位都在 `intake.md`。

## 一、用法的三条

1. 先判档：**A 直读 / B 需转换 / C 只能看图 / D 不能自动处理**。档位决定后面所有动作，判错档比不认识后缀更糟。
2. 本文件也没有的后缀：不许猜、不许当文本读，按 `intake.md` 的「未知类型待定」处置。
3. 转换一律**留原件**，产物写到 `复习资料\_生产\_迁移\conv\<科目>\`，不改原件、不改名冒充别的格式。

## 二、A 档：直接读，文字层可采信

| 后缀 | 通道 | 注意 |
|---|---|---|
| `.tex` | 直接读源码 | 公式即源码，比 OCR 可靠。`\input` / `\include` 拆成多文件时，主文件末尾的列表决定章节顺序；模板导言区的宏（`\newcommand`）先读，否则正文里的简写无法还原 |
| `.epub` | zip 解包，读 `OEBPS/*.xhtml` | 文字可采信；公式多半是图片，仍须看图。章节顺序看 `content.opf` 的 `spine`，不要按文件名排 |
| `.html` / `.htm` | 直接读 | 公式若用 MathJax，源码里保留 `\(…\)`，可直接转；若是图片，按 C 档 |
| `.mhtml` / `.mht` | 单文件网页存档，按 MIME 分段 | 取 `text/html` 段，图片为同文件内 base64。用文本编辑器看边界字符串 `------MultipartBoundary` |
| `.srt` / `.vtt` / `.ass` | 读字幕文本，按时间戳定位 | 录课字幕比音频转写可靠，单位写 `01:23:45`。口述的公式仍属「仅线索」 |
| `.xlsx` / `.xls` / `.csv` | 表格 | 本包 `.venv` 无 `openpyxl` / `pandas`；走 `workbuddy-sheetagent`，或让用户另存 csv。定位单位写「表名 + 行号」，不写页码 |
| 源码 `.c` `.cpp` `.h` `.py` `.java` | 直接读 | 程序设计科目的实验代码，用来对齐「本章涉及的库函数与语法点」；**不作为题目来源**，除非用户明确说是实验原题 |
| `.json` / `.yaml` / `.ini` | 直接读 | OJ 题库导出、配置，定位用 `key` 路径 |

## 三、B 档：需先转换

| 后缀 | 转换方式 | 注意 |
|---|---|---|
| `.doc`（Word 97-2003） | Word COM：`Documents.Open` → `SaveAs2(路径, 16)` 存 docx | 中文路径不许进命令行参数，用 UTF-8 清单传路径；转换后原件保留 |
| `.wps`（WPS 文字） | **不转**。让用户另存 docx / pdf；已有同名 pdf 时直接按 pdf 处理 | 总禁令：不装不用 WPS，**不得调用 KWPS COM**。见 `复习资料\_生产\_踩坑清单.md` 顶部 |
| `.rar` / `.7z` | `7z x -o<目录>` 解到 `_迁移\conv\` | Windows 自带 `tar` 只认 zip，不认 rar/7z。机器上没有 7z 就请用户解压，不要装 |
| 多页 `.tiff` / `.tif` | `fitz.open` 逐页 `get_pixmap(dpi=180)` | 一个文件常含几十页，**按页登记**（`文件名 pNN`），不要当一个图 |
| `.heic` / `.heif` | 需 `pillow-heif`；没有就请用户导出 jpg | iPhone 默认格式，`fitz` 打不开。**不要改名成 `.jpg` 冒充**，解码器不认这个后缀 |
| 微信 `.dat` | 手机端加密缓存，需按文件头做 XOR 解密 | 不确定就不要折腾，请用户从聊天记录「另存为」 |
| 加密 / 权限受限 PDF | `fitz.open` 仍可渲染 | `doc.needs_pass` 为真时问用户要密码；`get_text()` 可能为空，但看图重建不受影响 |
| `.djvu` | 需 djvulibre，机器上通常没有 | 没有就判「不能自动处理」，请用户转 pdf |
| `.note`（GoodNotes / Notability 原生） | 私有格式，**不处理** | 只能请用户导出 pdf；导出后按扫描件走 |
| `.apkg`（Anki） | zip + sqlite，`collection.anki2` 的 `notes.flds` 存正反面文本 | 定位「牌组 + 卡序」。卡片是他人整理，内容可信度按「仅线索」 |

## 四、C 档：只能看图，记录判定依据

| 场景 | 处理 | 判据 |
|---|---|---|
| 双栏 / 多栏 PDF | 先 `get_pixmap(dpi=110)` 看版面定栏数；两栏时按 `get_text('blocks')` 的 `x0` 分左右，或直接 `clip` 裁半页各看一次 | `get_text()` 返回的行左右交错、读不成句 |
| 整本翻拍（手机拍书） | 分三种缺陷处理：透视畸变按页框裁边；书脊阴影横向亮度不均，阈值化或换裁切位置；跨页断开先把两页拼起来再看 | 判据是**题干是否完整**，不是图是否清楚。跨页题（题干在一页、选项在下一页）最常见 |
| 缩排打印（6 / 9 张幻灯片一页） | `dpi=300` 起步，按 2×3 或 3×3 网格切块后逐块看 | 整页看会把公式看成糊块；切块后单张才够分辨率 |
| 白板 / 黑板照 | 反光区文字全失，请用户换角度补拍 | 反光处不要猜，标 `[反光不可辨]` |
| 公式截图 | 只能手打成 `$…$`，打完回教材核 | 禁止把 OCR 结果直接进 md；`intake.md` 第三节已定 |
| 手写笔记 | 逐张看，连笔与缩写常见；模糊处标 `[疑似: xxx]` | 不猜；猜错的公式比缺公式更贵 |

## 五、D 档：不能自动处理

| 类型 | 处置 |
|---|---|
| 网盘链接 / 云文档分享 | 先下载到该科目目录，再按后缀判档。链接本身不登记成「原件」 |
| 纸质原卷 | 只能拍照，按 C 档「整本翻拍」处理；拍完登记照片文件名与页码 |
| 课堂录音 | 有转写能力就转，标时间点；口述公式一律回教材核，不作定理依据 |
| 录屏 / 视频 `.mp4` `.mkv` | 按需抽帧（`ffmpeg -ss <时刻> -frames:v 1`）或转写，不整段看 |

## 六、未知后缀的处置（硬规则）

本文件与 `intake.md` 第二节都没有的后缀：

1. **不许猜**，不许当文本读，不许改名成已知后缀。
2. 在 `_原件.md` 状态列写「未知类型待定」，类型列写看到的实际后缀。
3. 回复里说明三件事：文件与后缀、已试过的通道及结果、需要用户确认什么（格式来源，或能否另存 pdf）。
4. 判为「不能自动处理」也要登记——否则下次会话会重新试探一遍，白花一轮。

`scripts\复习资料_原件.py` 会把未知后缀单独列出来并指向本文件对应档位。

## 七、登记口径（与 `intake.md` 配合）

- **同源多格式**（pdf + docx）分两行登记，但状态列必须写「同源副本（pdf 为主）」，引用一律以 pdf 为准。不写同源，第二册会把它当两份独立资料各配一遍题。
- **答案册**单列一行，类型写「答案册（附属）」。它是主干的附属物，不是主干本身；节号仍按主教材，页码按答案册自己的物理页。
- **重复副本**保留一份为主，另一份状态写「重复，未用」，**不删**。判据是同大小 + 首页文本同。
- **版本差异**：类型列带版本号（`第 4 版` / `第 5 版`），覆盖列写「按 X 版节号」。旧版笔记挂到新版节号上必定错位，宁可少用也不串版。
- **横跨多章**：`_原件.md` 的「已用」列在每次用完后回填册名，写第二册时先看这列，避免同一份 pdf 重复切一遍。

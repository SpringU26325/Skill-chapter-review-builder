# 素材接入与定位（Step 0 读这一份）

> **什么时候读**：开工前，手里只有 PDF / 课件 / 笔记 / 图片、主干还没定或刚定，还没开始写 md。

## 一、主干与补充

**主干**是这一册的骨架来源：它决定这章分几节、节号怎么写、例题与习题怎么编号、公式回哪里核对。**主干由用户指定，不预设为教材**——老师课件常常比教材更该当主干（进度、考法、课堂扩展都跟着它走），讲义、题库同理。教材只是最常见的一种主干。

判定一份资料够不够当主干，看三条，缺任一条就要用户补：

1. **能定结构**：有清晰的章 / 节划分，撑得起 `## X.Y` 的层级；
2. **能定编号**：节号、例题号、习题号成套（课件就是幻灯片号 `pNN`）；
3. **能核内容**：公式有可回看的原始形态（矢量文字层或页面渲染图），不是转述。

第 3 条意味着**笔记不能单独当主干**：笔记可以定结构、标重点，但公式无从核对，必须再配一份可核对的来源（教材或课件），否则写出来只是「看着像」。

材料还在工作区外时，请用户放到 `复习资料\<科目>\` 根层，或给出明确路径；工作区外也能原地只读使用，位置写绝对路径。**不改工作区外的原件**。放好后跑 `"<py>" "<skill>\scripts\复习资料_原件.py" <科目> --write` 登记。空工作区先用 `复习资料_init.py` 建骨架（见 `SKILL.md` 接手四步第 1 步）。

工作区**已有 `复习资料\` 却没有 `_配置.md`** 时，同样先跑 `复习资料_init.py` 补建：它扫既有源稿的 `@sub`，把教材版本与页码换算填成候选行。拿候选向用户确认一次（「按现有配置继续？」）即可开工，**不要空手问「教材在哪」**；用户否认，再按下一节重新定主干。候选里的「—（待确认）」「各册不一致」是要核的项，不是已定结论。

**用户没指定主干时，先问，不要自己挑一份就开工**（纯页数 / 空页检查、审计、重导出等不改内容的任务除外）：

- 列出手里实际有的资料（`复习资料_原件.py` 的盘点结果 + `_配置.md` 里登记的素材库），说明每一份能提供什么、缺哪条；
- 问「这次以哪一份为主干？」，并给建议——要教材页码 → 教材；课件进度与考法明显不同 → 课件；
- 用户说「你看着办」→ 选能同时满足三条的那份，说明理由并记进 `_配置.md`；
- 一份都满足不了 → **不开工**，直接说清缺哪一条（缺结构 / 缺编号 / 缺可核对的公式），等用户补。

主干定下来后写进 `复习资料\_生产\_配置.md` 的「主干」表：科目、主干文件、**位置**（工作区内写相对路径，工作区外写绝对路径）、类型、编号单位、页码换算。台账只记进度，不重复这些字段；换主干时改配置那一行，并在台账追加一条事实（何时、换成什么、旧主干停用）。

主干一旦指定，其余资料全部降为补充：主干是课件时，教材用来核公式、补更完整的推导，页码不再作基准，`@sub` 写「课件第 X 章 · pA–B（幻灯片号）」；主干是教材时，课件只补课堂扩展。

同一份主干有多份副本时，**先定用哪一份再记页码**，页码基准只认一份；副本在 `_原件.md` 状态列写「重复，未用」，不删。

冲突裁决顺序：**用户最新口径 > 主干的明确说明（绪论 / 正文 / 课件标注）> 补充资料（真题题面除外，题面照录）。**

课件节号与主干节号不一致时，按**主干**体系顺延并加「课堂扩展」标记，编号对照写进工作区台账 `复习资料\_生产\_台账.md`。

## 二、来源 → 通道表

**本表只列常见来源**，长尾后缀不在主流程展开——遇到表外后缀，读 `references/sources.md`，那里按「直读 / 需转换 / 只能看图 / 不能处理」四档给了转换命令。**表外后缀不许猜**；本文件与 `sources.md` 都没有时，在 `_原件.md` 状态列写「未知类型待定」并问用户。

| 来源 | 定位单位 | 文字层可信度 | 公式 / 内容来源 | 抽取 / 渲染通道 |
|---|---|---|---|---|
| 有书签 PDF | 物理页 `get_toc()`（1-based，非印刷页） | 可采信 | 文字层 + 页面图 | `page.get_text()`；`page.get_pixmap(dpi=180)` |
| 扫描 / 图片型 PDF | 物理页 | 无效（仅标题、页码可信） | 页面图 | `get_pixmap(dpi=180)` 逐页看 |
| PPTX / 旧 `.ppt` | 幻灯片号 `pNN` | 仅线索（`a:t`）；旧 `.ppt` 无 XML 文字层 | 渲染图 | 抽 `ppt/slides/slideN.xml` 的 `a:t` 定位；COM `Slide.Export(png,'PNG',1600,900)` 出图 |
| docx / md / txt | 文件 + 节号 | 可采信 | 文本 | 直接读 |
| 图片 / 板书照片 / 截图 | 文件名 + 序号 | 无效 | 图片 | 逐张看图；模糊处标 `[疑似: xxx]` |
| 真题卷（矢量 / 扫描） | 卷名 + 题号 | 矢量可采信，扫描无效 | 文字层 + 页面图 | `get_text()` 取题干，扫描件 `get_pixmap(dpi=180)` 逐页重建；题号写 `【真题 2024秋期末A卷 第3题】` |
| 手写笔记（照片 / 扫描） | 来源 + 页码 | 无效 | 仅线索 | 逐张看图；结论与公式都回主干核，不作定理依据 |
| zip / 目录 | — | 容器 | 解包后按本表判定 | 原始包勿动 |
| 音视频 / 网页 | 时间戳 / URL | 仅口述要点 | 转写 + 人工确认 | 标注来源与时间点，不直接当公式 |
| **表外后缀** | — | — | — | **读 `references/sources.md` 判档，不猜** |

**示意图只从主干裁**（`figures.md`）：主干 PDF 按页裁 PNG 落到 `_源稿\figures\<科目>\`，登记 `_图索引.md`；主干是课件就先转 PDF。补充资料里的图只在主干缺失时用，且要在图注或正文里标明来源。找不到原图就报缺失，**不凭印象重画**——复习资料里的图形符号必须是主干上的那一个。

## 三、可信度三级

- **可采信**：矢量文字层，可抄文字。
- **仅线索**：课件 `a:t`、目录页，只用来定位页号与标题。
- **无效**：图片里的公式、OCR 文本层。

**凡「仅线索」或「无效」，公式一律以渲染图视觉重建为准，禁止从文字层抄公式。**

### 内容可信度（补充资料专用：真题 / 笔记等）

文字层三级只回答「能不能抄」，不回答「对不对」。真题与笔记按内容再判一次：

| 来源 | 题目可信 | 答案可信 | 处理 |
|---|---|---|---|
| 真题原卷 + 官方答案 | 是 | 是 | 题面与答案照录，标 `【真题 …】` |
| 真题原卷，无答案 | 是 | 否 | 题干照录，答案自行求解并标「自行求解」 |
| 学长 / 他人笔记 | 否 | 否 | 只补解释，不作定理依据，冲突时以主干为准 |
| 本人课堂笔记 | 否 | 否 | 同上 |

补充资料只补充、不推翻主干，裁决顺序见第一节末。**真题题面是唯一例外**：照录，不改写成主干的风格。

每科原件登记在 `复习资料\<科目>\_原件.md`：文件、类型、来源日期、覆盖章节、内容可信度、状态、**已用**（用完回填册名，防第二册重复切同一份 pdf）。新拿到的资料先登记再动，避免下次会话不知道这份 pdf 是什么。

登记不必手写：`"<py>" "<skill>\scripts\复习资料_原件.py"` 扫科目目录，列出未登记文件、未知后缀、疑似重复、登记失效（表里有、磁盘没有）四类；加 `--write` 把未登记行直接追加进 `_原件.md`，状态填「未使用」。

## 四、Step 0 的三步

### 1. 定位

主干是 PDF 时用 `doc.get_toc()` 拿书签，确认物理页范围（1-based）。

**以书签为准，不要凭 `@sub` 反推**——历史上出过页码标错 20 页、成品副标题跟着错的情况。

非 PDF 来源改用其定位单位（幻灯片号 `pNN`、文件+节号、时间戳），并在 `@sub` 与自检报告里写明单位。

### 2. 判定文字层可信度

抽 2–3 页 `page.get_text()`。若公式乱码（`[~]`、下标错位、竖排图注被打散成单字），判定为**扫描件 + OCR 文字层，不可信**，改走 `page.get_pixmap(dpi=180)` 逐页看图。

文本层只用来确认标题层级、例题编号、页码，**绝不采信其公式**。课件 `a:t`、图片型公式的文字层属「仅线索 / 无效」，公式同样必须看渲染图。

### 3. 看图节奏

逐页看，**每页间隔 2–3 秒**，不要连发——连续快速调用会触发限流（返回空或 `withheld`），遇到就退避重试，不要原地连刷。PPT 渲染图、板书照片同样适用。

## 五、定位单位的书写

PDF 写物理页并注明非印刷页；课件写 `pNN`（幻灯片序号）；其他写「文件 + 节号」。

`@sub`、题卡来源标注、自检报告三处必须用同一种单位。

# 素材接入与定位（Step 0 读这一份）

> **什么时候读**：开工前，手里只有 PDF / 课件 / 笔记 / 图片，还没开始写 md。

## 一、主干与补充的分层

教材 PDF 提供**骨架、节号与公式编号体系**；其他来源只补主干没有或主干不同的内容。

教材 PDF 优先取工作区 `Ebooks\`（现收：张三慧《大学物理学》上册第五版及其学习辅导、Strang《线性代数导论》第五版、北大版《高等数学》第三版上/下册、谭浩强《C 程序设计》第六版教材与配套课件）。目录里没有对应科目时向用户要，**不要拿二手笔记或课件冒充主干**；页码一律按该 PDF 的物理页记。

同一本书有多份副本时，**先定用哪一份再记页码**，页码基准只认一份；副本在 `_原件.md` 状态列写「重复，未用」，不删。`Ebooks\大一上` 现有两份《大学物理学(上册)第五版》，同为 368 页、同为扫描件，页码基准一致，但后续核对只对一份。

冲突裁决顺序：**用户最新口径 > 课堂明确说明（绪论 / 课件标注）> 教材 > 外部资料（真题题面除外，题面照录）。**

课件节号与教材节号不一致时，按教材体系顺延并加「课堂扩展」标记，编号对照写进工作区台账 `复习资料\_生产\_台账.md`。

## 二、来源 → 通道表

**本表只列常见来源**，长尾后缀不在主流程展开——遇到表外后缀，读 `references/sources.md`，那里按「直读 / 需转换 / 只能看图 / 不能处理」四档给了转换命令。**表外后缀不许猜**；本文件与 `sources.md` 都没有时，在 `_原件.md` 状态列写「未知类型待定」并问用户。

| 来源 | 定位单位 | 文字层可信度 | 公式 / 内容来源 | 抽取 / 渲染通道 |
|---|---|---|---|---|
| 有书签 PDF | 物理页 `get_toc()`（1-based，非印刷页） | 可采信 | 文字层 + 页面图 | `page.get_text()`；`page.get_pixmap(dpi=180)` |
| 扫描 / 图片型 PDF | 物理页 | 无效（仅标题、页码可信） | 页面图 | `get_pixmap(dpi=180)` 逐页看 |
| PPTX / 旧 `.ppt` | 幻灯片号 `pNN` | 仅线索（`a:t`）；旧 `.ppt` 无 XML 文字层 | 渲染图 | 抽 `ppt/slides/slideN.xml` 的 `a:t` 定位；COM `Slide.Export(png,'PNG',1600,900)` 出图 |
| docx / md / txt | 文件 + 节号 | 可采信 | 文本 | 直接读 |
| 图片 / 板书照片 / 截图 | 文件名 + 序号 | 无效 | 图片 | 逐张看图；模糊处标 `[疑似: xxx]` |
| 真题卷（矢量 / 扫描） | 卷名 + 题号 | 矢量可采信，扫描无效 | 文字层 + 页面图 | `get_text()` 取题干，扫描件 `get_pixmap(dpi=180)` 逐页重建；题号写 `【真题 2024秋期末A卷 第3题】` |
| 手写笔记（照片 / 扫描） | 来源 + 页码 | 无效 | 仅线索 | 逐张看图；结论与公式都回教材核，不作定理依据 |
| zip / 目录 | — | 容器 | 解包后按本表判定 | 原始包勿动 |
| 音视频 / 网页 | 时间戳 / URL | 仅口述要点 | 转写 + 人工确认 | 标注来源与时间点，不直接当公式 |
| **表外后缀** | — | — | — | **读 `references/sources.md` 判档，不猜** |

## 三、可信度三级

- **可采信**：矢量文字层，可抄文字。
- **仅线索**：课件 `a:t`、目录页，只用来定位页号与标题。
- **无效**：图片里的公式、OCR 文本层。

**凡「仅线索」或「无效」，公式一律以渲染图视觉重建为准，禁止从文字层抄公式。**

### 内容可信度（外部资料专用）

文字层三级只回答「能不能抄」，不回答「对不对」。真题与笔记按内容再判一次：

| 来源 | 题目可信 | 答案可信 | 处理 |
|---|---|---|---|
| 真题原卷 + 官方答案 | 是 | 是 | 题面与答案照录，标 `【真题 …】` |
| 真题原卷，无答案 | 是 | 否 | 题干照录，答案自行求解并标「自行求解」 |
| 学长 / 他人笔记 | 否 | 否 | 只补解释，不作定理依据，冲突时以教材为准 |
| 本人课堂笔记 | 否 | 否 | 同上 |

外部资料只补充、不推翻教材，裁决顺序见第一节末。**真题题面是唯一例外**：照录，不改写成教材风格。

每科原件登记在 `复习资料\<科目>\_原件.md`：文件、类型、来源日期、覆盖章节、内容可信度、状态、**已用**（用完回填册名，防第二册重复切同一份 pdf）。新拿到的资料先登记再动，避免下次会话不知道这份 pdf 是什么。

登记不必手写：`python "<skill>\scripts\复习资料_原件.py"` 扫科目目录，列出未登记文件、未知后缀、疑似重复、登记失效（表里有、磁盘没有）四类；加 `--write` 把未登记行直接追加进 `_原件.md`，状态填「未使用」。

## 四、Step 0 的三步

### 1. 定位

主干 PDF 用 `doc.get_toc()` 拿书签，确认物理页范围（1-based）。

**以书签为准，不要凭 `@sub` 反推**——历史上出过页码标错 20 页、成品副标题跟着错的情况。

非 PDF 来源改用其定位单位（幻灯片号 `pNN`、文件+节号、时间戳），并在 `@sub` 与自检报告里写明单位。

### 2. 判定文字层可信度

抽 2–3 页 `page.get_text()`。若公式乱码（`[~]`、下标错位、竖排图注被打散成单字），判定为**扫描件 + OCR 文字层，不可信**，改走 `page.get_pixmap(dpi=180)` 逐页看图。

文本层只用来确认标题层级、例题编号、页码，**绝不采信其公式**。课件 `a:t`、图片型公式的文字层属「仅线索 / 无效」，公式同样必须看渲染图。

### 3. 看图节奏

逐页看，**每页间隔 2–3 秒**，不要连发——连续快速调用会触发限流（返回空或 `withheld`），遇到就退避重试，不要原地连刷。PPT 渲染图、板书照片同样适用。

## 五、定位单位的书写

PDF 写物理页并注明非印刷页；课件写 `pNN`（幻灯片序号）；其他写「文件 + 节号」。

`@sub`、题卡来源标注、自检报告三处必须用同一种单位。

## 六、PowerPoint COM 纪律

与 Word COM 同一套：

- 单实例；`Presentations.Open(path,$true,$false,$false)`；
- 导出后 `Close()` → `Quit()` → `ReleaseComObject` → `GC`；
- **禁止强杀 POWERPNT**；
- 中文路径**不能写进命令行参数、也不能写进 .ps1 字面量**（跨进程传参 / ANSI 解码都会乱码，表现为找不到文件或静默挂住），必须用 **UTF-8 清单文件**传路径，命令行只留 ASCII 的清单路径。**路径本身含中文不影响导出**——这一点在 Word COM 上已实测（11-11），PowerPoint 同样适用；误判常源于把「传参乱码」当成「路径不支持」；
- `Slide.Export` 的输出路径必须是**反斜杠**，正斜杠报「无法将 ^0 保存到 ^1」；
- 在 Bash 里调 powershell 会被安全策略拦截，须用 PowerShell 工具。

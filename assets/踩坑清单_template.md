# 踩坑清单

> **什么时候读**：改引擎、写公式、调 Word COM、查分页之前。
> **记什么**：已经踩过、且会再踩的**事实**——症状、根因、处置、怎么验证。不记过程与猜测。
> **不记什么**：与科目相关的口径（记号、术语、表述、单位、教材与规范的出入）→ 写 `复习资料\<科目>\<科目>_学科约定.md`；进度与页数 → 写 `_台账.md`；已确认但没修的缺陷 → 写 `_待修缺陷.md`。
> 本文件由 `init` 从 `assets\踩坑清单_template.md` 生成一次，之后**由使用过程追加**，`init` 不再覆盖。条目按「日期 · 现象」起头，便于后来者判断新旧。

## 〇、总禁令

- **不装、不用 WPS**，不得调用 `KWPS` COM。`.wps` 一律让用户另存 docx / pdf 再处理。
- **不装库、不建 `.venv`**：解释器由用户指定，缺依赖先问，默认答案是换解释器而不是 `pip install`。
- **不在工作区外写文件**：中间产物只落 `复习资料\_生产\`，宁可在盘符根目录报错，也不要静默降级。

## 一、Word COM 与并发

（占位，遇到再补。已知通用事实：）

- **`docProps/app.xml` 的 `<Pages>` 恒为 1**：那是 python-docx 写的默认值，不是 Word 回写的真实页数。页数只认 Word COM 的 `ComputeStatistics(2)`。
- **禁止强杀 `WINWORD` / `POWERPNT`**：强杀会留下 `.asd` 恢复副本与 Resiliency 注册表项，用户下次开 Word 弹「文档恢复」，误点会拿旧版覆盖成品。确实要杀，先查 `~$xxx.docx` 对应文档的 `Saved`，True 才 `Close(0)`。
- **`RPC_E_CALL_REJECTED`（0x80010001）= 目标实例卡在模态框**，不是路径或权限问题：同一目标换 ASCII 路径也失败、`Close` 也失败。处置是让用户点掉那个框。
- **前台调用会「假挂死」**：脚本拉起 GUI 后调用可能提前返回并留下孤儿进程。COM 实验一律后台跑 + 逐步落盘日志，才能分辨「真卡住」与「工具提前返回」。

## 二、LaTeX → OMML 公式坑（md 级写法禁忌）

- **除单位外，除法一律写 `\frac`**：转换器只在 `mrow` 恰好三个子元素、且这一处除法独占整条公式时才折成分数线；同一条公式里再有一个 `=`、`+`、`\geqslant` 就退化成普通字符斜杠，Word 画成长斜杠、压在上下标上。`\mathrm{m/s}` 这类单位才用 `/`。判据见 skill 的 `references/md-dialect.md` 第 3 节。
- **`\begin{cases}` 里禁写 `\quad` / `\qquad`**：token 切分会把 `\begin` 与 `\end` 分到两段，转换抛 `MissingEndError`，整条公式以 LaTeX 源码形态落进正文，而 `audit` 仍报「转换失败 0」。条件用 `&` 分列。
- **`$$` 必须与公式同行、整行只放公式**：孤行 `$$`（公式夹在下一行）会让引擎产出空公式、公式内容降级成正文；行中 `$$x^2$$` 只从第二个 `$` 起配对，前后各剩一个孤儿 `$` 印进段落。两种都曾让 `audit` 全绿。`lint` 2.7.9 起对孤行、未在本行闭合、行中三种写法报 ERROR。
- **`[[…]]` 不是矩阵**：引擎只认 `\begin{bmatrix}`，双方括号会被拆成独立字符平铺，且 `audit` 全绿。
- **`\underline{…}` 会整条公式失败**：转换出 `<munder>`，引擎不支持；填空写在数学外，直接 `____`。

## 三、排版与分页

- **围栏代码块（三反引号）不被识别**：引擎只认 `:::code`，围栏行当普通段落，代码被拼成一整段流水文本，`lint` 与 `audit` 全绿，只有渲染图看得出来。
- **`## 一页速查` 与 `## 附录 · 题库` 强制另起页**：附录内容不足整页时末页必然留白，属固定版式，别当缺陷反复重排。
- **页眉页脚小字不要用最淡的灰**：白底对比度不足 3:1 时打印出来读不出；引擎里分「页眉页脚」与「装饰灰」两档，改配色只动取色的那一处。

## 四、流程与状态

- **md 源稿是唯一可迭代资产**，构建出的 docx、渲染图都是抛弃品。
- **增量判据看 mtime**：docx 被 Word 打开另存过，mtime 会前移到源稿之后，于是「源稿比成品新」不成立、改了源稿也不重建，漂移永久隐身。体检法：把 md 重建到临时目录，比对 `word/document.xml` 的 SHA-256。
- **并行会话要抢锁**：同一册同时构建就是后写覆盖前写。单册构建也走引擎自带的科目锁，别手工并行跑。

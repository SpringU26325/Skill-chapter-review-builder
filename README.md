# 学习资料工作区

把**一章大学理工科教材**，稳定地变成一份可交付、可复现、可质检的 Word 复习资料（`.docx`）。

工作流规则全部在 `chapter-review-builder` skill 里：`.agents/skills/chapter-review-builder/`（v0.11.0）。**本 README 是工作区说明，不属于 skill 包**——包内保持零宿主耦合、零机器绝对路径、无 `.git`，复制时不会把本文件或仓库历史带走。

---

## 一句话判断

这个 skill 的价值**不在「AI 写讲义」，而在工程链与检查链**：教材定位 → md 源稿 → 自建引擎 → LaTeX 原生公式的 Word → 页数/公式/引用/视觉验收 → 交付。md 源稿是唯一可迭代资产，docx 随时可以重出。

它最强的是「同一类事重复做几十次不出错、改一行源稿只重出受影响那一份」；代价是前置条件重（Windows + Office + 教材页码 + 六项自检），启动成本高。**适合一学期多章、且会反复返工的场景；不适合偶尔做一页纸。**

## 适合做什么

| 场景 | 具体交付 |
|---|---|
| **单章新做** | 给定教材 PDF 与页码范围，产出上/中/下/拓展分册；每个知识点配题、章末题库、一页速查、本章脉络 |
| **已交付资料返工** | 重排、补题、核公式、查页数、重新导出 PDF；增量重建只重出 md 比 docx 新的那份 |
| **质检与验收** | 公式转换失败数、分式类型（`bar`/`lin`）、页数与空页、记号登记、关键页逐页 PNG 看图 |
| **长期多章迭代** | 一次只处理一章，跨册不写编号、来源标注可追溯、进度只写台账；目前 38 份 |
| **新科目接入** | 不改引擎，加一份 `<科目>_notation.md` 与可选 `<科目>_lint.py` |

口语说「提纲」「总结」「速查」「知识脉络」「章节结构」也会命中，但成品文件名与内部标题仍叫**「复习资料」**——不会因为你说「做个提纲」就真做成骨架。

## 不适合做什么

| 别拿来干这个 | 原因 | 该走什么 |
|---|---|---|
| 做 PPT | 版式体系是私有 md 方言 + 自建引擎，与演示稿无关 | 宿主的 Presentations skill |
| 通用 Word 排版 / 美化任意 docx | 七种容器、题卡三行、自动分页是专用约定 | 通用文档 skill |
| 改 Python 脚本、代码调试、纯问答 | 与复习资料无关 | 通用能力 |
| 一次做完一整本书 / 跨章汇总 | 硬约束「一次只处理一章」 | 分章多次 |
| 没有教材页码锚定的自由创作 | 公式以渲染后重建为准，禁止悬空引用 | 先补来源再开工 |
| Linux / macOS / WPS | 页数与导出走 Word COM，公式转换要 Office 自带 `MML2OMML.XSL`；WPS 静默失败 | 换环境 |
| 把课堂笔记随手排成「一份 Word 讲义」 | 没走六项自检与配题/题库/速查结构，产物不是复习资料 | 通用文档 skill |

**边界已实测**（11-12，Codex）：「看 `print_today.py` 有什么问题」与「做线代第 1 章 PPT」两条，在候选技能清单里确实有本 skill 的前提下都**没有命中**；后者走的是 `Presentations`。

## 输入与产物

| | 路径 / 说明 |
|---|---|
| 主干素材 | `Ebooks\` 教材 PDF，**只读**；课件、板书、笔记作补充层 |
| 源稿 | `复习资料\_源稿\<科目>_第X章*.md`（私有 md 方言，唯一可迭代资产） |
| 成品 | `复习资料\<科目>\<同名>_复习资料.docx` |
| 现状 | 38 份：线代 1–9 章、高数 1–6 章、物理 1–3 章 |

一份合格成品要通过**六项自检**：覆盖度（知识点↔题目对应表）、准确度、公式语法、交叉引用、视觉验收、排版逻辑（8–15 页，超出必须拆册）。前四项是文本层检查，查不出公式挤成一团，所以关键页必须逐页看图。

## 工作流骨架

接手三步 → 写 md → 构建 → 检查 → 交付：

1. 读 `复习资料\_台账.md`，确认这一章的页码、分册、是否返工。
2. 写 md，`复习资料_lint_md.py` 把 ERROR 清零再构建。
3. `复习资料_重建.py` 增量出 docx（改过引擎才用 `--all`）。
4. `复习资料_audit.py` + `复习资料_页检.py` + 科目 lint；线代另跑 `线性代数_lint.py`。
5. 渲染 `--prepare` → 后台执行 `render.ps1` → `--render` 看图 → `--clean` 清场，然后交付并只更新台账。

最常用的三条（在工作区根目录执行）：

```bash
python "<skill>\scripts\复习资料_重建.py" --dry
python "<skill>\scripts\复习资料_重建.py" <科目> --pdf
python "<skill>\scripts\复习资料_audit.py" <md> <docx>
```

`<skill>` 指 **SKILL.md 所在目录**，不同宿主挂的位置不同，别照抄某个具体路径。完整命令速查、阶段索引与 COM 纪律以 `SKILL.md` 为准——**这里刻意不复制**，两份必然漂移。

## 运行环境

- **Windows + Microsoft Office**，WPS 禁用（接管 `Word.Application` 后 COM 兼容层静默失败，且不带 `MML2OMML.XSL`）。
- Python 依赖：`python-docx`、`latex2mathml`、`lxml`、`pymupdf`，优先用工作区 `.venv`。
- 动 Word 前先确认 `WINWORD` 进程数为 0、过程目录无 `~$` 锁文件；`render.ps1` 带 180 秒看门狗，日志里的 `TIMEOUT|` 才是挂死的证据。

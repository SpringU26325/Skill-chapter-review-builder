# chapter-review-builder

把一章内容编译成可直接打印的 Word 复习资料：以用户指定的主干资料（教材 / 课件 / 讲义等）定骨架，其他资料作补充。输入是 Markdown 源稿，输出是 `.docx`；公式为 Word 原生 OMML，可编辑、可缩放。

适用：单章复习资料的初做、返工、补题、重排、质检。不适用于通用 Word 排版美化。

## 成品结构

固定顺序，页数舒适区 8–12 页，硬上限 15 页，超过必须拆册（上 / 中 / 下 / 拓展）。

| 位置 | 内容 |
|---|---|
| 页眉 | 科目、章节号与章节名（教材版本与页码写在源稿 `@sub`） |
| 核心考点 | 本章解决的问题与考试落点 |
| 本章脉络 | 层级缩进的树状结构，可含行内公式，每行可点击跳转 |
| 正文 | 按节展开：讲解、注释、国内考法、例题；每个知识点配一道题 |
| 附录 | 易错点、课后习题、一页速查 |

## 跳转

文档自带内部链接，不需要手写标记：

- 首页「速达」指向 本章脉络 / 易错点 / 附录题库 / 一页速查
- 「本章脉络」的每一行连到对应小节
- 小节标题下的「对应题目」连到附录里那一道题

标题带大纲级别，Word 左侧导航窗格按三级展开，标题左侧可折叠。链接由标题名与附录标签推导：附录条目写成 `【课后习题 6.5 第 1 题】` 的册子才有题目跳转，写成 `【习题 3.1】`（那是题号）的没有。

## 公式

链路：LaTeX → MathML → `MML2OMML.XSL` → OMML。

`latex2mathml` 默认把 `1/2`、`x/2` 输出为斜杠分式（OMML 中 `m:type="lin"`），Word 显示为压扁的斜杠。引擎在出口把折出来的 `lin` 改成上下堆叠（`bar`）；**单位**（`\mathrm{m/s}`）例外，保留 `lin`——它本来就该是 `m/s`，不该排成 m 压在 s 上。判据是分子分母是否全为正体，`audit` 对本册的 `lin` 逐条复核：全正体算单位（预期），出现斜体即报 `[FAIL]`。

但**折分式不是引擎做的，是 `MML2OMML.XSL`**：只有 `mrow` 恰好三个子元素、且这一处除法独占整条公式时才折。同一条公式里再有一个 `=`、`+`、`\geqslant`，`/` 就落成普通字符——Cambria Math 的实心斜杠跨整个字身，紧跟带下标的量时看着像压在下标上（`mv_\theta^{2}/l`、`1/\mu_s`、`\gamma=5/3` 都是这样）。引擎够不着：`_force_bar()` 只遍历 `m:f`，退化形态里根本没有 `m:f`。所以写法上**除单位外一律 `\frac`**，`5/3`、`T/T_0` 也写；判据与对照见 `references/md-dialect.md` 第 3 节「除法只有一个写法」。

函数名与极限另走两条路：`\sin`、`\det`、`\max` 这类转换出来是斜体，引擎一律补正体；带下标的 `lim` / `max` / `det` / `gcd` / `Pr` 等把下标从右下角改到正下方，行内也压；相邻两个函数名（`\ln\sec x`）会被并成一个 run，引擎按算子名表切开，变量前补一个 U+2009 细空格、名后跟括号不补。重音（`\dot` / `\hat` / `\vec`）贴字母排，叠加重音按「窄内宽外」重排，否则 Word 的固定重音槽会把点顶到上一层。

## 插图

教材里有些内容本身就是图：流程图符号、结构框图、受力图、波形图。这类用 `复习资料_裁图.py` 从主干 PDF 按页裁成 PNG，落到 `_生产\_源稿\figures\<科目>\` 并登记 `_图索引.md`；md 里写 `![图注](figures/<科目>/<名字>.png)` 独占一行，引擎居中插图、图注用浅色小字，并保证图与图注不被分页拆开。

**表格与公式都不走这条通道**：表格写成 md 表，公式走 LaTeX 重建——两者都可编辑、可搜索、放大不糊。图也只裁图形，不把教材上的图注与说明裁进来。

清晰度上限等于主干扫描分辨率：以 174 dpi 的扫描件为例，`--dpi 300` 只是插值，不会多出细节；换一套主干按实际分辨率算（原图像素宽 ÷ 页面英寸）。详见 `references/figures.md`。

## 构建与校验

空工作区先建骨架（幂等，台账不覆盖；不建 .venv、不装库）：

```bash
"<py>" "<skill>\scripts\复习资料_init.py" <科目> --dry
"<py>" "<skill>\scripts\复习资料_init.py" <科目>
```

日常只需一条重建命令，`--pdf` 顺带出页数；**并行会话必须带 `--only <册名>`**，否则科目关键字会连坐别人正在改的章：

```bash
"<py>" "<skill>\scripts\复习资料_重建.py" --only <科目>_第<X>章 --pdf
```

`<skill>` 指本目录（`SKILL.md` 所在层），`<py>` 指工作区 `.venv\Scripts\python.exe` 或 `CRB_PYTHON` 指定的解释器——**不要写裸 `python`**，PATH 上那套没有依赖。其余脚本、参数与退出码见 `SKILL.md` 的「命令速查」。

三层检查，职责不重叠：

1. **lint**（构建前）：私有方言、行内矩阵、结构块内裸公式、`$$` 的三种坏写法、未知容器类型、容器内表格、题卡三行、骨架 `@sub`、速查收尾等写法问题。**退出码 2 = 有 ERROR**（0 才可交付）。
2. **audit**（构建后）：公式转换失败数、私有区字符、空槽 `m:d`、非单位 `lin` 分式、图片数对账。任何一项不合格即打 `[FAIL]` 并**退出码 1**（更早版本里 audit 恒退 0，那时的「audit 通过」只等于「脚本没崩」）。
3. **视觉验收**：公式挤压、上下标重叠脚本查不出，需渲染 PDF 后按「看图清单」抽检。

WARN 不阻断，但须在自检报告里逐条说明。

## 版本与升级

当前版本 **2.8.0**，对外发布序列 v2.4.1 → v2.5.0 → v2.7.0 → v2.7.11 → v2.8.0。2.8.0 是结构整理版：引擎拆成四个模块、`CHANGELOG` 分段、文档口径订正，**产出逐字节不变，单独升到本版不需要重建**。逐版明细见 `CHANGELOG.md`（2.6.9 及更早见 `CHANGELOG-archive.md`），升级注意见 `RELEASE_NOTES.md`。

如果你是从 **v2.7.0 或更早**升上来，除了升到 2.8.0，还要把成品重建一遍——做这三件事：

1. **重建一遍，别信旧成品**。`audit` 现在会判红（`[FAIL]` 退 1），此前产出、没重建的 5 份册子会立刻红：线性代数第 10 章上 / 第 8 章中、高等数学第 2 章上 / 第 2 章中 / 第 4 章中（共 12 处 `m:d` 空槽）——存量缺陷显形，重建即绿。两处成品字形修复（`\left(-\frac…\right)` 空槽方框、`0\,^\circ` 的点线方框与 9.7 pt 空隙）同样只在重建后生效。全量重建：`复习资料_重建.py --all --pdf`。
2. **写法按新口径**：除单位外一律 `\frac`（连 `5/3`、`T/T_0` 也写）；`$$` 必须与公式同行、整行不放正文；容器类型只能是七个，写错 lint 报 ERROR。
3. **`init` 不再跳过缺配置的工作区**：`_配置.md` 缺失时立即补建，并从既有源稿的 `@sub` 预填主干候选；同时生成 `_踩坑清单.md` 骨架。

## 环境

| 项 | 要求 |
|---|---|
| 系统 | Windows |
| Office | Microsoft Office |
| Python | `python-docx`、`latex2mathml`、`lxml`、`pymupdf` |

WPS 不支持：接管 `Word.Application` 后 COM 层静默失败，且不带 `MML2OMML.XSL`。页数与 PDF 导出、公式转换各依赖其一。

解释器默认取工作区根目录的 `.venv\Scripts\python.exe`，可用 `CRB_PYTHON` 覆盖；没有 `.venv` 时先问用户，脚本不会自建虚拟环境，也不会替你装包——取舍规则见 `SKILL.md`「运行环境与依赖」。

## 已知限制

- 版式只有一套：七种容器加自动分页，不支持自定义风格。
- 一次处理一章，页码范围由人工指定。
- PDF 文字层不可信，OCR 常把数学符号识别错（`λ` 识别为 `入`）。公式必须回主干按页面图重建。
- **变量紧接函数名不留缝**：`x\sec^2x` 排成 `xsec²x`。相邻的两个函数名已经拆开，但「变量 + 函数名」属隐式乘法的留白，改动面大且可能带动分页，暂未处理。
- **极限与带下标的算子一律压到正下方**：行内 `$\lim_{x\to0}$` 也比 TeX 的行内排法占高，含这类符号的正文行距会被带大。
- 插图清晰度受主干扫描分辨率限制，无法超过原书扫描的 dpi（174 dpi 的扫描件，`--dpi 300` 也只是插值）。
- Word COM 偶发阻塞，脚本设 180 秒熔断，只结束本次自己拉起的实例，阈值由 `CRB_RENDER_TIMEOUT` 调整。
- **导出期间不要双击打开 Word 文档**：Windows 会通过 DDE 把文件交给正在导出的那个实例，收尾时可能被一并关闭。脚本已加保护——检测到外来文档就拒绝退出（日志 `QUIT SKIPPED`），此时需手动保存并关闭那个 Word 窗口。

## 目录约定

目录由 `init` 生成，完整清单与各自职责见 `SKILL.md` 的「工作区目录」表。三件要知道的：

- `复习资料\<科目>\` 放本科目原件与 `_成品\`；`复习资料\_生产\_源稿\` 放各章 Markdown 与记号表；
- `_生产\_配置.md` 记「现在是什么」（主干、编号单位、页码基准），`_生产\_台账.md` 记「发生过什么」（进度、页数），两者不重叠；
- **素材库不是约定目录**：已有书库（如 `Ebooks\`）原地只读使用，位置登记进配置的「素材库」，不必搬进工作区。

md 方言见 `references/md-dialect.md`，写作风格见 `references/wording.md`。补充资料的文件类型与转换命令见 `references/sources.md`——**按需读**，只在遇到表外后缀时打开。
